# MICR Font Licensing Notes

This project expects a MICR E-13B font file named `MICR.ttf` in the project directory.

The `MICR.ttf` file currently included in this archive is a **placeholder** and is **NOT** a real MICR font.
It is provided only as a filename stub so the script runs without crashing when you are experimenting
with layout and non-bank use.

For any **real-world banking or check-printing use**, you must:

1. Obtain a properly licensed MICR E-13B font from a trusted vendor or an open-licensed source.
2. Replace this placeholder `MICR.ttf` with the actual binary font file.
3. Review and comply with the license terms for that font.

Examples of search terms:
- "MICR E-13B font"
- "MICR E13B open source font"

Because fonts are typically copyrighted, this project does **not** redistribute a real MICR font.
You are responsible for ensuring that the font you use is legally licensed for your intended use.
